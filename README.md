# tweak36.github.io

Website of TWEAKFAILS: games, apps and the TWEAKFAILS YouTube channel, served at https://tweakfails.com (see `CNAME`).

Plain static HTML, CSS and a few lines of JS, no build step.

- `index.html`: studio home page
- `assets/css/site.css`, `assets/js/site.js`: shared styles and small enhancements (mobile menu, screenshot switcher, click-to-load YouTube)
- `assets/fonts/`: self-hosted Outfit and Inter (SIL Open Font License)
- `<app>/privacy.html`: privacy policy for each app
- `app-ads.txt`: AdMob authorized sellers

Contact: support@tweakfails.com
